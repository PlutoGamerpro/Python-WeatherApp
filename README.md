# 🌦️ Weather Application

A simple and responsive weather application that allows users to search for **any city** and instantly view the current weather conditions.

## ✨ Features

- 🔍 Search for weather by city name
- 🌡️ Displays the current temperature
- ☁️ Shows a weather description (e.g., Clear, Cloudy, Rainy)
- ⚡ Fast and easy-to-use interface

## 🚀 How It Works

1. Enter the name of any city.
2. Press **Search**.
3. View the city's:
   - 🌡️ Temperature
   - ☁️ Weather condition

---

> 💡 **Example:** Search for **London**, **Tokyo**, or **New York** to instantly see the current weather.
